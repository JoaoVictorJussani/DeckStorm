# 🖼️ Image Occlusion - Guide d'utilisation

## Qu'est-ce que l'Occlusion d'Image ?

L'**Occlusion d'Image** est une fonctionnalité puissante de DeckStorm qui vous permet de créer des flashcards visuelles en masquant des zones spécifiques d'une image. C'est l'outil idéal pour apprendre :

- 🫀 **Anatomie** - Masquez les parties du corps pour tester vos connaissances
- 🗺️ **Géographie** - Cachez les noms de pays, villes ou régions
- 💻 **Code** - Masquez des parties de diagrammes ou d'architectures
- 📊 **Diagrammes** - Testez votre compréhension de schémas complexes
- 🎨 **Art** - Apprenez les parties d'œuvres d'art ou de compositions

## Comment créer une carte d'occlusion d'image ?

### Étape 1 : Sélectionner le type de carte

Lorsque vous créez une nouvelle carte, vous verrez deux options :

1. **Carte Textuelle** 📝 - Carte traditionnelle avec question/réponse
2. **Occlusion d'Image** 🖼️ - Nouvelle carte visuelle avec zones masquées

Cliquez sur **Occlusion d'Image** pour commencer.

### Étape 2 : Télécharger une image

- Cliquez sur la zone de téléchargement
- Sélectionnez une image depuis votre ordinateur
- Formats acceptés : JPG, PNG, GIF, WEBP
- Taille maximale : 10 MB

💡 **Conseil** : Utilisez des images claires avec des zones bien définies pour de meilleurs résultats.

### Étape 3 : Dessiner les zones d'occlusion

Une fois l'image chargée :

1. **Cliquez et glissez** sur l'image pour créer des rectangles
2. Chaque zone est automatiquement **numérotée** (1, 2, 3...)
3. Les zones utilisent des **couleurs vives** pour une meilleure visibilité
4. Créez autant de zones que nécessaire

#### Gestion des zones

- **Supprimer une zone** : Cliquez sur le bouton 🗑️ à côté de la zone
- **Effacer toutes les zones** : Utilisez le bouton "Effacer toutes les zones"
- **Changer l'image** : Cliquez sur "🔄 Télécharger une image"

### Étape 4 : Ajouter un titre (optionnel)

Vous pouvez ajouter un titre personnalisé pour votre carte, par exemple :
- "Anatomie du cœur"
- "Pays d'Europe de l'Ouest"
- "Architecture MVC"

Si vous ne spécifiez pas de titre, "Occlusion d'Image" sera utilisé par défaut.

### Étape 5 : Enregistrer

Cliquez sur **Ajouter la carte** pour sauvegarder votre création !

## Comment réviser avec les cartes d'occlusion ?

### Mode d'étude

Lorsque vous étudiez un deck contenant des cartes d'occlusion :

#### 🔒 Face avant (Question)
- L'image s'affiche avec les **zones masquées** en couleur
- Chaque zone affiche son **numéro** en blanc
- Essayez de vous rappeler ce qui se cache sous chaque zone

#### 🔓 Face arrière (Réponse)
- Cliquez pour **retourner la carte**
- L'image complète est révélée
- Les contours des zones restent visibles pour référence
- Les numéros apparaissent dans les coins

### Évaluation

Comme pour les cartes textuelles :
- ✅ **Correct** - Vous avez bien répondu
- ❌ **Incorrect** - À réviser

## Conseils pour de meilleures cartes

### ✅ Bonnes pratiques

1. **Images claires** : Utilisez des images haute résolution avec des zones bien définies
2. **Zones logiques** : Créez des zones qui correspondent à des concepts distincts
3. **Taille appropriée** : Ne créez pas de zones trop petites ou trop grandes
4. **Nombre optimal** : 3-7 zones par image pour une mémorisation efficace
5. **Cohérence** : Utilisez le même style d'images pour un même sujet

### ❌ À éviter

1. **Images floues** : Difficiles à interpréter
2. **Trop de zones** : Plus de 10 zones rend la révision difficile
3. **Zones qui se chevauchent** : Peut créer de la confusion
4. **Images avec texte illisible** : Assurez-vous que le texte est lisible

## FAQ

### Q : Puis-je modifier une carte d'occlusion après l'avoir créée ?
**R** : Actuellement, vous devez supprimer et recréer la carte pour modifier les zones.

### Q : Combien de zones puis-je créer ?
**R** : Il n'y a pas de limite technique, mais 3-7 zones est optimal pour l'apprentissage.

### Q : Les images sont-elles stockées en sécurité ?
**R** : Oui, les images sont stockées sur le serveur dans un dossier dédié avec des noms uniques.

### Q : Puis-je utiliser des images trouvées sur Internet ?
**R** : Assurez-vous d'avoir les droits d'utilisation des images. Privilégiez les images libres de droits ou créez les vôtres.

### Q : La fonction fonctionne-t-elle hors ligne ?
**R** : Non, vous devez être connecté pour créer et réviser des cartes d'occlusion.

### Q : Puis-je exporter mes cartes d'occlusion ?
**R** : Cette fonctionnalité n'est pas encore disponible mais pourrait être ajoutée dans une future version.
